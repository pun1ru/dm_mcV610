# LK 保护态反馈异常：禁止循环发送 0x81

日期：2026-11-26

## 现象

- 末三轴 LK 电机使用 `MODE_POSITION` 和绝对多圈反馈。
- 使能状态下 J4、J5 多圈反馈正常。
- 进入 `ARM_PROTECTED` 后，只有 J6 继续更新 `feedback.timestamp`，J4/J5 停止更新。
- 保护态多圈值出现精确的 `±2π` 跳变，但编码器计数没有对应转过一圈。

## 定位

保护态原实现每 2 ms 对每个位置轴连续发送：

```text
DATA[0] = 0x81  Motor Stop
DATA[0] = 0x92  Read Multi Angle
```

实测确认，高频循环发送 `0x81 Motor Stop` 会使部分 LK 节点在 Stop/Run
之间停止响应 `0x92`。使能后发送 `0x88 Motor Run`，反馈恢复。

## 处理

保护态不再循环发送 `0x81`。位置轴只做只读反馈维护：

```text
每 2 ms:   0x92 Read Multi Angle
每 100 ms: 0x9C Read State2
每 200 ms: 0x9A Read Error
```

反馈存活由 `feedback.timestamp` 统一判断：

```text
timestamp 变化 -> 更新 last_feedback_ms
timestamp 不变且超过超时 -> 只标记 MOTOR_NO_FEEDBACK
```

超时不再修改 `multi_angle_rad/multi_angle_deg`，避免硬件绝对多圈角被折叠成单圈角。

## 补充：0x88 Motor Run 只能发一次

后续实机确认，`0x88 Motor Run` 也不能周期重发。

实测现象：

- 从保护态退出时发送一次 `0x88`，位置闭环正常。
- 周期重发 `0x88` 后，LK 会出现类似“输出全部给 0”的效果，运动和保持能力明显异常。
- 停止重发并每次只保留保护退出边沿的一次 `0x88` 后恢复正常。

因此 `Motor Run` 当前只在以下状态切换时发送一次：

```text
PROTECTED -> ENABLE
PROTECTED -> TEST
PROTECTED -> HOST
```

以下状态之间切换不再重发：

```text
ENABLE <-> TEST
ENABLE <-> HOST
```

保护态反馈维护保持为：

```text
每 2 ms:   0x92
每 100 ms: 0x9C
每 200 ms: 0x9A
```
